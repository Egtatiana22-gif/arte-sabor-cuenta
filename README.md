# Arte y Sabor — Servicio de cuentas

Servicio web para registro e inicio de sesión.

## Tecnologías
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- JWT

## Configuración
Configura las variables de entorno DB_PASSWORD y JWT_SECRET.
Base de datos: arte_sabor_cuentas.
Esquema SQL: database/arte_sabor_cuentas.sql

## Ejecución
Ejecuta la aplicación con .\mvnw.cmd spring-boot:run.
El servicio utiliza el puerto 8081.
